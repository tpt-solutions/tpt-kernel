# tpt-k-root

The tpt-k root server: the planned first user-space process, acting as the capability authority. The capability service is host-tested. The binary is a stub, and the kernel handoff is not built yet.

Part of tpt-k, a permissively licensed, capability-based microkernel ecosystem by TPT Solutions.

## Status

What is built, and what is still open, is in [the layer checklist](../todos/root.md). Each crate's README has its own `Status` section. Crates are under `crates/`.
