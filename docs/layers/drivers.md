# tpt-k-drivers

The tpt-k user-space drivers and driver manager. The restart policy and device encodings are host-tested. The planned WebAssembly driver host is not built yet.

Part of tpt-k, a permissively licensed, capability-based microkernel ecosystem by TPT Solutions.

## Status

What is built, and what is still open, is in [the layer checklist](../todos/drivers.md). Each crate's README has its own `Status` section. Crates are under `crates/`.
