# tpt-k-toolchain

The tpt-k build system (tpt-k-build CLI) and bootable image generation.

Part of tpt-k, a permissively licensed, capability-based microkernel ecosystem by TPT Solutions.

## Status

What is built, and what is still open, is in [the layer checklist](../todos/toolchain.md). Each crate's README has its own `Status` section. Crates are under `crates/`.
