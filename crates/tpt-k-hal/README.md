# tpt-k-hal

The tpt-k hardware abstraction layer core: common hardware data structures.

Part of tpt-k, a permissively licensed, capability-based microkernel ecosystem by TPT Solutions.

## Status

Implemented, host-tested: Core hardware resources: MMIO regions, I/O port ranges and interrupt lines, with the collision rule the root server checks before it grants them.
